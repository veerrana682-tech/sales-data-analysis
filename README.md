# 📊 Sales Data Analysis Project

## 📌 Project Overview
This project analyzes sales data using Excel, MySQL, Pandas, and Power BI.

## 🛠 Tools Used
- Excel
- MySQL
- Pandas
- Power BI

## 📈 Key Insights
- Total Sales and Profit
- Region-wise performance
- Top selling product
- Category-wise profit
